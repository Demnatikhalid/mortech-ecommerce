Déposez la vidéo de la page À propos ici.

Nom du fichier requis: `about-video.mp4`

Placez le fichier vidéo (MP4) dans ce dossier pour que la page À propos puisse l'afficher à l'URL `/assets/about-video.mp4`.

Exemple (depuis la racine du projet) :

cp path/to/your/video.mp4 frontend/public/assets/about-video.mp4

Redémarrez le serveur de développement si nécessaire.
